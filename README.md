## 概要
スタジオゼブラに関するリポジトリ。次の内容が含まれる。

- 公式サイト
- 予約管理アプリケーション

## リポジトリ構成

zebra/
├── studio-website/          # Astroで開発
├── booking-saas-app/        # Next.jsで開発
├── .github/                  # GitHub関連の設定
└── README.md                # このファイル

## ロードマップ
### 1. 公式サイトの作り替え
WordPressで構築された公式サイトを、Astroを使って再構築する。
サイトパフォーマンスが悪いこととSEO向上を図るため。

### 2. 予約管理アプリケーションの開発
公式サイトの作り替えが完了したら、予約管理アプリケーションを開発する。
Next.jsを使って開発し、予約の自動管理、通知機能、予約フォームとカレンダーの連携などを実装する。

### 3. 継続的な改善と機能追加
ユーザーフィードバックを基に、公式サイトと予約管理アプリケーションの継続的な改善と新機能の追加を行う。

### 4. SaaS化の検討
将来的には、他のスタジオやビジネス向けに予約管理アプリケーションをSaaSとして提供することも検討する。
